Twork Builder adds 223+ Gutenberg blocks for healthcare, corporate, and WooCommerce-based websites.

== Description ==

Twork Builder is a multi-block Gutenberg plugin focused on fast page building with reusable sections.

Key features:

* 223+ custom blocks for hero, cards, FAQs, grids, timelines, and content sections.
* Healthcare and hospital-focused building blocks (doctors, departments, facilities, patient content).
* Corporate and CSR sections for modern business websites.
* WooCommerce-ready blocks for product categories and featured products.
* Responsive editor/front-end parity and conditional script loading.

The plugin works as a standalone block plugin and can be used with most modern WordPress themes.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/twork-builder` directory, or install through the WordPress Plugins screen directly.
2. Activate the plugin through the `Plugins` screen in WordPress.
3. Open the Block Editor and search under the `Twork Builder Blocks` category.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

No. WooCommerce is optional and only required for WooCommerce-specific blocks.

= Is this plugin compatible with the Site Editor? =

Yes. Blocks are registered with block metadata and can be used in posts, pages, and block templates.

= Can I use this plugin with any theme? =

Yes. It is designed to be theme-agnostic, but visual output may vary by theme styles.
